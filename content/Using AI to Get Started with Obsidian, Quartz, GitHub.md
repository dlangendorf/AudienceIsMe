# What Have I Done?

A few days ago, out of the blue, I decided to try [Quartz](https://vapenyk.xyz) (a static site generator) with [Obsidian](https://obsidian.md), my note-taking (aka life) app of choice. What an adventure that was/is. I'm still working out the kinks.

While I am against using AI for creative work, I am not against using it to help set up technology. I attempted to do this installation by myself but quickly saw how complicated it was going to be with so many moving parts.

So I chose Google's Gemini to help set up Obsidian, Quartz, and [GitHub](https://github.com). I definitely needed help.
![[CleanShot 2026-08-26 at 13.03.23@2x.png|500]]
Later that night . . . 

Later the next day . . . 

I'm still at it.

I'm not a neophyte setting up technology. I've built PCs, loaded OSes, wiped computers and started from scratch, set up Wordpress blogs, even dabbled with Ghost Publishing and Obsidian, mucked around in Terminal, and so on. Obsidian, Quartz, and GitHub shouldn't present a problem for a "simple" install, should it?

Wrong.

So many needles in the haystack: Obsidian requires this, Quartz requires that, GitHub does this and wants it done a certain way. Check this, uncheck that, remove the { } syntax from this line of code.

Look, without Gemini and an excellent screenshot maker I never would have gotten Audience Is Me up and running on this platform. I guess this "site" is now "vibe-coded."

But these words -- all mine. AI-free.
